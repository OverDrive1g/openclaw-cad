# 05. DFM: CNC 3018 и лазер 5 W

## CNC 3018, шпиндель 200 W

Это лёгкий станок. Жёсткость и мощность низкие, поэтому правила жёстче, чем
для промышленного CNC. Типовая фреза — 3.175 мм.

| Проверка | Лимит | Как мерить |
|---|---|---|
| Внутренний радиус угла | ≥ радиус фрезы + 0.5 мм; для 3.175 мм → **R ≥ 2 мм** | цилиндрические грани |
| Глубина кармана | ≤ 4×D фрезы; для 3018 лучше 2–3× | проекция граней кармана на −Z |
| Тонкая стенка | ≥ 1.5–2 мм | расстояние между противоположными гранями |
| Отверстия | сверлить; мин. Ø 1.5–2 мм фрезой, до Ø1 мм сверлом | диаметры цилиндров |
| Доступ инструмента | только сверху, без поднутрений | нормали граней, 3 оси |
| Крепление | зона под прижимы/скотч | габариты + компоновка |
| Материалы | фанера, МДФ, пластик; алюминий — лёгкие проходы; сталь — нет | — |
| Глубина за проход | дерево/пластик 1–2 мм; алюминий 0.1–0.3 мм | решается CAM, не геометрией |
| Внешние скругления | ≥ 0.5–1 мм | меньше сколов |

### Что важно помнить

- Фреза не режет внутренний угол «в ноль». Если в ТЗ прямой угол, он всё равно
  станет радиусом фрезы — закладывайте R ≥ 2 мм заранее.
- 3 оси: фреза достаёт только сверху. Любое поднутрение — отдельная операция
  или переработка.
- Плоская фреза делает острый корень «стенка–дно». Скругление корня — шаровая
  фреза, дополнительная операция.
- Различайте геометрическое ограничение и стоимость. «Можно, но дорого» —
  не то же самое, что «нельзя».

### Порядок DFM-ревью

1. Соберите: материал, заготовку, фрезеровка/точение, оси, допуски.
2. Измерьте радиусы, глубины карманов, толщины стенок, недостижимые полости.
3. Сравните с правилами, укажите источник (этот файл / CAD_RULES / гайд).
4. Для каждого `fail` — правка с числом и координатой.

## Лазер 5 W

| Проверка | Лимит | Комментарий |
|---|---|---|
| Материал | шпон ≤3 мм, картон, фанера 1–2 мм; не металл | медленно, с прогонами |
| Kerf | ~0.1–0.3 мм | паз = толщина + 2×kerf |
| Внутренние углы | радиусы ≥ 0.5 мм | острые углы прожигаются |
| Тонкие перемычки | < 0.5 мм выгорают | не делать |
| Формат | DXF/SVG из FreeCAD | Draft/Shape export |

### Практика

- Kerf зависит от материала, мощности, скорости и фокуса. Перед серией —
  тестовый рез: квадрат 20×20, замер штангелем, поправка в контуре.
- Для пазов «шип-паз» режьте тестовую пару: номинальный паз почти всегда
  требует поправки на kerf.
- 2D-контур берите из 3D-модели проекцией/развёрткой, а не рисуйте отдельно:
  так меньше расхождений.

## Экспорт

```python
import Part

Part.export([doc.getObject("Part")], "/path/to/part.step")

import Mesh
Mesh.export([doc.getObject("Part")], "/path/to/part.stl")
```

Для лазера: выделите грань/эскиз и экспортируйте в DXF через Draft/Shape export
или `import TechDraw`/`Draft` в зависимости от задачи.

## Отчёт

```markdown
## DFM: <part>, CNC 3018, фанера 6 мм, фреза 3.175
- Внутренние радиусы: min 1.0 мм → fail (нужно ≥2.0)
- Карман: глубина 12 мм, D=3.175 → 3.8×D → review (для 3018 лучше ≤2–3×)
- Стенка: 1.8 мм → pass при лимите ≥1.5
- Доступ: поднутрение в [x,y,z] → fail для 3 осей
```

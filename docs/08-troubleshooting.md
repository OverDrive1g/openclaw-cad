# 08. Типовые проблемы

## Мост не отвечает

**Симптом:** `Failed to connect to FreeCAD ... Connection refused`.

Проверьте по порядку:

1. FreeCAD GUI запущен?
2. Верстак Robust MCP Bridge → **Start MCP Bridge** нажат?
3. В консоли есть `XML-RPC: localhost:9875`?
4. `curl http://localhost:9875` возвращает `501` (это норма) или отказ?
5. MCP-клиент перезапущен после изменения конфига?

FreeCAD нужно запускать в обычной графической сессии. Попытка поднять GUI из
фонового процесса даёт `no Qt platform plugin could be initialized`.

## FreeCAD упал по памяти

**Симптом:** процесс убит, документ не сохранён, MCP-ответ оборван.

Причины:

- одна гигантская булева цепочка в одном `execute_code`;
- слишком большой скрипт, ответ не влезает в лимит MCP;
- множество сложных `cut/fuse` без промежуточного `recompute`.

Лечение:

- 1 вызов = 1–3 операции;
- `doc.recompute()` и `doc.saveAs()` после каждого этапа;
- разбивать деталь на простые тела и собирать постепенно;
- при падении перезапустить FreeCAD руками (не из фонового процесса) и открыть
  последний `.fcstd`.

## Потерялись несохранённые документы

FreeCAD хранит открытые документы в памяти. Падение — и всё, что не сохранено,
исчезает. Поэтому `saveAs()` — не «в конце», а после каждого существенного шага.
Если документ не сохранён, восстановить его из MCP-логов можно только частично.

## `Part.makePrism` не существует

В FreeCAD 1.1.4 такого метода нет. Используйте профиль + extrude:

```python
wire = Part.makePolygon(pts + [pts[0]])
face = Part.Face(wire)
solid = face.extrude(Vector(dx, dy, dz))
```

## Тор даёт не тот диаметр

Наружный диаметр тора = `2 × (R + r)`, где `R` — радиус центральной линии,
`r` — радиус трубки. Для точного диаметра кольца берите разность цилиндров.

## Два solids вместо одного

Причины:

- `fuse` тел, касающихся ровно по границе, без нахлёста;
- отверстие больше босса, через который оно проходит;
- деталь разрезана плоскостью или щелью.

Проверяйте `len(shape.Solids)` после каждой склейки. Нахлёст 0.1–0.2 мм обычно
решает проблему.

## Неверный масштаб STEP

Импортированный STEP может быть в метрах или дюймах. Проверьте `BoundBox`:
если диагональ меньше 1 мм или подозрительно круглая — это почти наверняка
другие единицы. Масштабируйте осознанно, а не «подгоняйте» до совпадения.

## Отверстия меньше номинала после печати

FDM даёт на 0.2–0.4 мм меньше. Компенсируйте в модели или сверлите после печати.
Для M3: отверстие 3.2–3.4 мм, затем метчик/саморез по задаче.

## Нависания «есть», но поддержки не нужны

Смотрите не только угол, но и площадь и высоту. Маленькая грань под 30° может
печататься без поддержек. Решение принимается по фактам: угол, площадь, высота,
критичность поверхности.

## MCP-ответ обрезан

Причина — слишком длинный вывод `execute_code`. Печатайте только сводку:
`print({...})`, а не дамп всех граней. Тяжёлые проверки разбивайте на шаги.

## Клиент не видит новые тулы

После правки `openclaw.json` нужен перезапуск OpenClaw: MCP-снимок кэшируется.
В Codex — новый запуск `codex exec`.

## Это не ошибка: `curl` отдаёт 501

XML-RPC-сервер отвечает `501` на HTTP GET. Это признак живого моста, а не сбоя.
Для настоящей проверки используйте MCP `get_connection_status`.

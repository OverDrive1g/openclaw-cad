# 03. Проверка модели

Проверка идёт слоями: сначала дешёвая, потом дорогая. Нельзя заменять числа
красивым скриншотом, а скриншот — проверкой топологии.

## Уровень 0. Скриншот

MCP `execute_code` возвращает изображение (по умолчанию). Смотрите:

- форма соответствует ТЗ;
- отверстия на месте, их количество верное;
- нет явных артефактов: торчащих тел, дыр, «слипшихся» элементов;
- ориентация и масштаб адекватны.

Скриншот подтверждает подозрение, но **не является измерением**.

## Уровень 1. Числовая сверка

Считайте ожидаемые значения аналитически и сравнивайте с фактами из FreeCAD.

```python
import FreeCAD as App

doc = App.getDocument("flange")
obj = doc.getObject("Flange")
shape = obj.Shape

b = shape.BoundBox
facts = {
    "bbox_mm": [round(b.XLength, 3), round(b.YLength, 3), round(b.ZLength, 3)],
    "volume_mm3": round(shape.Volume, 3),
    "area_mm2": round(shape.Area, 3),
    "faces": len(shape.Faces),
    "edges": len(shape.Edges),
    "solids": len(shape.Solids),
    "shells": len(shape.Shells),
    "valid": shape.isValid(),
}
print(facts)
```

Что сверять:

| Факт | Ожидание | Допуск |
|---|---|---|
| Габариты | размеры из ТЗ | ±0.01 мм |
| Объём | аналитический расчёт | ±0.5% |
| Количество solids | 1 для монолитной детали | ровно 1 |
| Количество отверстий | по ТЗ | ровно N |
| Позиции отверстий | координаты из ТЗ | ±0.01 мм |

Пример аналитического расчёта для фланца:

```
V = W·D·H
  − 4·π·(HOLE_D/2)²·H
  − 4·(объём конуса зенковки − объём цилиндра внутри конуса)
```

Если объём расходится больше чем на 0.5%, ищите причину: забытая операция,
двойное вычитание, неверный радиус, два тела вместо одного.

## Уровень 2. Топология B-rep

`shape.isValid()` — быстрая проверка. Для подробностей:

```python
if not shape.isValid():
    shape.check(True)  # печатает ошибки BRepCheck_Analyzer в консоль
```

Критерии для монолитной детали:

- `isValid() == True`;
- `len(shape.Solids) == 1`;
- `len(shape.Shells) == 1` (для простой детали);
- нет «дыр» и вырожденных граней.

Если solids больше одного — тела не связаны. Частые причины: `fuse` по границе
без нахлёста, отверстие больше босса, деталь разрезана плоскостью.

## Уровень 4. FEM (если деталь нагружена)

FreeCAD + CalculiX. Считайте не «красиво/некрасиво», а запас прочности:

```
запас = предел текучести / максимальное эквивалентное напряжение
```

Для пластика запас ≥ 2 — разумный старт, если нет отдельного требования.
Учитывайте, что FDM-деталь анизотропна: прочность по Z ниже, чем в плоскости
слоёв. FEM по изотропному материалу этого не покажет — делайте поправку.

## Формат отчёта

```markdown
## Деталь: <name>, ревизия <N>
- Технология: Q1 Pro / PLA, сопло 0.4, слой 0.2
- Габариты: 100.0 × 100.0 × 5.0 мм (ТЗ: 100 × 100 × 5) — pass
- Объём: 49 701.6 мм³ (расчёт 49 701.6) — pass
- Тела: 1 solid, isValid=True — pass
- Стенки: min 2.4 мм (лимит ≥ 1.2) — pass
- Нависания: 0 мм² ниже 45° — pass
- Ориентация: плашмя, поддержки не нужны
- Не проверено: прочность при падении, УФ-старение
```

Всегда указывайте, что **не** проверялось. Отсутствие находок не означает
бланкового одобрения.

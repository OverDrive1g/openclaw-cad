# 09. Чек-лист

## Перед моделированием

- [ ] Есть ТЗ: назначение, размеры, материал, технология, нагрузки.
- [ ] Спорные размеры уточнены, а не угаданы.
- [ ] Понятно, какие поверхности/отверстия критичны.
- [ ] Выбраны единицы: мм.
- [ ] FreeCAD запущен, мост `connected`.

## После моделирования

- [ ] Все размеры — именованные переменные.
- [ ] Одна деталь — один документ с понятным именем.
- [ ] `.fcstd` сохранён.
- [ ] Скриншот соответствует ТЗ.
- [ ] Габариты совпадают с ТЗ (±0.01 мм).
- [ ] Объём совпадает с аналитическим расчётом (±0.5%).
- [ ] `isValid() == True`.
- [ ] `len(shape.Solids) == 1` для монолитной детали.
- [ ] Отверстия: количество, диаметры, позиции.
- [ ] Нет двух тел из-за `fuse` по границе.
- [ ] Посадки заданы зазором, а не «в ноль».

## Перед печатью на Q1 Pro

- [ ] Стенки ≥ 0.8 мм (комфортно ≥ 1.2).
- [ ] Нависания проверены; поддержки обоснованы.
- [ ] Ориентация выбрана по поддержкам, прочности и качеству поверхностей.
- [ ] Горизонтальные отверстия компенсированы.
- [ ] Мосты ≤ 10–15 мм или поддержаны.
- [ ] Отверстия на столе имеют фаску/другую ориентацию.
- [ ] Материал и слой указаны в README.
- [ ] `.stl` экспортирован из проверенной модели.

## Перед CNC 3018

- [ ] Внутренние радиусы ≥ 2 мм (фреза 3.175).
- [ ] Глубина кармана ≤ 2–3×D.
- [ ] Стенки ≥ 1.5–2 мм.
- [ ] Нет поднутрений и недостижимых полостей.
- [ ] Есть зона под крепление заготовки.
- [ ] Материал реален для 200 W.
- [ ] `.step` экспортирован.

## Перед лазером

- [ ] Материал тонкий и подходящий (шпон/картон/фанера).
- [ ] Учтён kerf, есть тестовый рез.
- [ ] Внутренние радиусы ≥ 0.5 мм.
- [ ] Нет перемычек < 0.5 мм.
- [ ] `.dxf`/`.svg` экспортирован из 3D-модели.

## Перед сдачей

- [ ] Отчёт с фактами и ссылками на лимиты.
- [ ] Явно указано, что не проверялось.
- [ ] Влад/заказчик посмотрел скриншот и подтвердил.
- [ ] Файлы лежат в ожидаемой папке, версия/ревизия понятны.

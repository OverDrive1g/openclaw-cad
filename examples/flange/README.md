# Пример: фланец 100×100×5

Деталь для проверки пайплайна: плита 100×100×5 мм, четыре отверстия Ø4 на
квадрате 80×80 мм, зенковка Ø7×1 мм с верхней стороны.

## Файлы

- `flange.py` — параметрический исходник;
- `flange.fcstd` — документ FreeCAD (создаётся скриптом);
- `preview.png` — скриншот из FreeCAD.

## Запуск

```bash
freecadcmd examples/flange/flange.py
```

Или через MCP `execute_code`: вставьте содержимое скрипта и выполните.

## Ожидаемые факты

- габариты: 100 × 100 × 5 мм;
- объём: 49 701.55 мм³ (расчёт по формуле в скрипте);
- 1 solid, `isValid() == True`;
- 4 отверстия, 4 зенковки.

Скрипт сам печатает фактический объём, ожидаемый объём, ошибку в процентах и
число тел. Это и есть числовая сверка уровня 1.

## Что проверить

1. `volume_error_pct` < 0.5.
2. `solids == 1`.
3. `valid == True`.
4. Скриншот: отверстия по углам, фаски сверху.
5. DfAM: плита плашмя, нависаний нет, поддержки не нужны.

## Результат проверки

Скрипт прогнан на FreeCAD 0.19 (API Part совместим с 1.1.x):

```
bbox_mm: [100.0, 100.0, 5.0]
volume_mm3: 49701.549
expected_volume_mm3: 49701.549
volume_error_pct: 0.0
solids: 1
valid: True
```

`overhangs.py` на этой детали: `down_area_mm2 = 0`, поддержки не нужны.

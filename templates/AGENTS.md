# AGENTS.md — правила CAD-проекта

Этот файл читает Codex CLI и агент перед работой с моделями.

## Среда

- FreeCAD 1.1.x GUI запущен, Robust MCP Bridge слушает `localhost:9875`.
- MCP-сервер: `freecad-mcp`, режим `FREECAD_MODE=xmlrpc`.
- Первый вызов любой сессии — `get_connection_status`. Не `connected` → стоп.

## Моделирование

- Только FreeCAD Part API через MCP `execute_code`.
- Запрещены OpenSCAD, cadgen, build123d, слайсеры и генераторы G-code
  (кроме случая, когда пользователь явно попросил OpenSCAD).
- Все размеры — именованные переменные в начале скрипта.
- Одна деталь — один документ с понятным именем.
- 1 вызов `execute_code` = 1–3 булевы операции.
- После каждого этапа: `doc.recompute()`, `doc.saveAs()`.
- `.fcstd` — исходник, `.step`/`.stl`/`.dxf` — производные.

## Проверка

- Скриншот + числовая сверка (bbox, volume, solids) для каждой детали.
- `isValid() == True`, `len(shape.Solids) == 1` для монолита.
- Для печати — DfAM-чек; для CNC/лазера — DFM-чек.
- Ожидаемый объём считать аналитически, допуск ±0.5%.

## Грабли

- `Part.makePrism` не существует → `Part.Face(wire).extrude(vec)`.
- Тор: наружный Ø = `2 × (R + r)`.
- `fuse` по границе без нахлёста даёт два solids.
- Гигантские булевы цепочки убивают FreeCAD по памяти.
- Несохранённые документы теряются при падении.

# Скрипты для `execute_code`

Это не CLI-утилиты, а готовые фрагменты для MCP-тула `execute_code`. Скопируйте
нужный файл в вызов (или его содержимое) и подставьте имя документа/объекта.

| Файл | Назначение |
|---|---|
| `measure.py` | Габариты, объём, площадь, грани, тела, валидность |
| `check_geometry.py` | Проверка B-rep и подробный вывод ошибок |
| `overhangs.py` | Сводка по смотрящим вниз граням для DfAM |
| `export.py` | Экспорт STEP/STL из выбранного объекта |

Все скрипты печатают компактный JSON/dict, чтобы не упираться в лимит вывода MCP.
